## NP-FW-HUB-001
author: NeurOne Software Engineering
text: **§2.5: who may read the warranty token. WARRANTY_TOKEN (0x0010) is served to any central that has encrypted the link, and Just Works pairing needs no secret (OI-SIMFW-72), so a patient's phone on a clinic helmet reads the clinic's token. The hub has no owner's link to restrict it to; the mechanism is a decision owed (docs/human-input/oi-priv-33-warranty-token-release.md). Meanwhile the apps store a hub-delivered token only for a helmet whose warranty owner has consented on that install (REQ-SHDR-08 (e)). No firmware changed (OI-PRIV-33, NP-PRIV-ANALYSIS-004, GitHub #961).**
