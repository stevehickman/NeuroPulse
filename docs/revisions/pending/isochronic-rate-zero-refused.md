The hub's EEG retune path refuses a retune to 0, a different case. Owner: Core + Firmware.

Tests tagged `REQ-NPPS-33#a`: `an_isochronic_rate_of_zero_is_refused_but_a_binaural_beat_of_zero_is_allowed` and `an_isochronic_rate_of_zero_is_a_validation_error_and_a_binaural_beat_of_zero_is_not`. A Compose field can still hold a typed 0, which the validator now refuses at signing.
