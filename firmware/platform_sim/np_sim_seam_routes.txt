# NeurOne Firmware-in-the-Loop Simulator: the seam route table (HOST ONLY)
# Document: NP-SIM-FW-001 §30 (REQ-SIMFW-02; OI-SIMFW-02, OI-SIMFW-06, OI-SIMFW-14)
#
# One row for every symbol of the SW-02 platform contract: the global functions
# firmware/platform/src/np_platform_stub.c defines, whose number is NP_SW02_PLATFORM_SYMBOL_COUNT
# (np_sw02_platform_hal.h) and is asserted by the cross-build census (np_platform_census.cmake).
# The row says what the twin does with the seam.  scripts/check-sim-seam-routes.ts compares every
# row with the tree, so a seam added to or removed from the contract, or a definition added to or
# removed from this layer, fails CI until the row is written.  No count is stated here: the gate
# prints the counts it finds.
#
# Columns (whitespace separated):
#   seam         the contract symbol
#   disposition  model          defined in this layer and answered by a module on the bus, keyed (kind, index)
#                infra          defined in this layer and answered by the twin itself (a clock, a TEST key,
#                               the GATT relay, the SPI link to the safety MCU), not by a module
#                unrouted       defined in this layer; reports itself as `unrouted` and returns a failure
#                firmware-host  defined by the device's own source under NPTEST_HOST, which this layer links
#                absent         not defined in the twin: no source the twin links calls it
#   where        the file that defines it, relative to firmware/platform_sim/ ("-" when absent)
#   space        what the seam's first argument addresses, as the contract declares it:
#                socket-index   0-based socket INDEX space (np_sw02_platform_hal.h: "socket_id is INDEX
#                               space (0-based)"); the page's 1-based socket number is converted once, in
#                               the page (NP-SIM-FW-001 §12), and never reaches this layer
#                pair           the stimulation electrode pair, the firmware's own number, passed through
#                side           the side of a one-part module (ear clip, nasal probe), passed through
#                slot           the firmware's slot number (the retired zone-slot PBM path and
#                               firmware/pbm); no route exists, so the twin translates nothing
#                channel        an EEG channel of the one front end
#                partition      a log partition (np_log_part_t)
#                char-id        a GATT characteristic id (np_gatt_server.h)
#                none           the seam addresses one part or the hub itself
#   item         for unrouted and absent rows, the open item under which the seam gets a route or its
#                caller is linked; "none" where no item promises one (the reason is in §30); "-" otherwise
#
