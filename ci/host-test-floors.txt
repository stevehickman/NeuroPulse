# ci/host-test-floors.txt — per-target executed-line floor for every host test.
#
# NP-SW-CI-001 §6.14, OI-SWCI-14 (second half). One line per target in
# ci/host-test-partition.txt, as `<ctest name> <lines>`:
# the number of distinct in-repo source lines that target executes when it
# runs ALONE on a --coverage build. Measured, not chosen.
#
# Why. The partition manifest catches a target renamed or swapped; it cannot
# catch a target that still passes after cases were deleted from it. Deleting
# a case removes the lines only it reached, so this count falls below the floor.
# It does not see a pure duplicate case, or an assertion weakened on the same
# line — see the header of scripts/check-host-test-floors.ts.
#
# What enforces it:
#   safety-mcu-ci.yml / firmware-cross-build.yml, job host-tests (every relevant
#     PR) — scripts/check-host-test-floors.ts --class C / --class B on a
#     --coverage build; a target below its floor fails the job. Above passes.
#   build-all.yml (weekly) — the same for all targets at once.
#   scripts/check-ci-scope.ts (correspondence E, every PR) — this file names
#     exactly the targets in ci/host-test-partition.txt, so a new target
#     without a floor fails its own PR.
#
# Adding a host test: add its line here too. To measure every floor:
#   cmake -B build/cov -G Ninja -DCMAKE_BUILD_TYPE=Debug -DNP_BUILD_TESTS=ON \
#         -DCMAKE_CROSSCOMPILING=OFF \
#         -DCMAKE_C_FLAGS=--coverage -DCMAKE_EXE_LINKER_FLAGS=--coverage firmware
#   cmake --build build/cov
#   bun scripts/check-host-test-floors.ts build/cov --write
# Lowering a floor is deliberate: do it in the PR that removed the coverage,
# and say why. Raising one after adding cases is welcome, never required.
